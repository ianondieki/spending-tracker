# Screenshots

Recorded by `ScreenshotTest` (Roborazzi on Robolectric, native graphics) every time `./gradlew testDebugUnitTest`
runs, at 360×800 and 412×915 dp in light and dark, one PNG per screen and state. File names:
`<screen>-<width>x<height>-<light|dark>.png`. They exist so the orchestrator can review the design without a device.
