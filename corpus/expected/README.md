# corpus/expected — cross-engine parity dumps

Generated by `pnpm --filter @hesabu/pack-engine dump` from the TypeScript engine. One file per corpus JSONL
(`<provider-dir>/<file>.expected.jsonl`) plus `demo-inbox.expected.jsonl` for `corpus/demo/demo-inbox.jsonl`.
`packages/pack-engine/src/dump.test.ts` fails when these files drift from the engine's output; the Kotlin engine in
`android/` asserts it produces byte-identical files. Never edit these by hand: fix the engine or the pack and re-run.

## Inputs both engines must use

| Input | `sender` | variables for `account_ref_template` | `received_at` when the line has none |
|---|---|---|---|
| every `corpus/**/*.jsonl` except `demo/` and `expected/` | the line's `sender` | `sim_msisdn_masked=07XXXXX000`, `acct_mask=***000` | `2000-01-01T00:00:00+03:00` (the dump prints `received_at: null`) |
| `corpus/demo/demo-inbox.jsonl` | the line's `sender` | `sim_msisdn_masked=07XXXXX123`, `acct_mask=XXX456` | never missing |

Post-processing (dedupe, transfer pairs, balance chain) runs per input file over all its parsed messages; the balance
chain never changes a line, so it is not dumped.

## Output: one JSON object per input line, in input order

Canonical serialisation: keys sorted lexicographically at every level, no whitespace, `\n` after every line, UTF-8,
integers for cents, `null` for absent values, strings escaped only as JSON requires (`"`, `\`, control characters;
no `\/`, no `\uXXXX` for printable characters).

| `outcome` | keys |
|---|---|
| `not_ours` | `index`, `sender`, `received_at`, `outcome` |
| `unknown` | + `raw_hash` |
| `ignored` | + `family_id`, `raw_hash`, `amount_cents`, `balance_after_cents`, `occurred_at`, `external_ref` (nulls when the family did not capture them) |
| `parsed` | + `id`, `account_ref`, `provider`, `external_ref`, `family_id`, `pack_id`, `pack_version`, `type`, `direction`, `amount_cents`, `fee_cents`, `balance_after_cents`, `occurred_at`, `counterparty` (`name`, `kind`, `ref_masked`, `paybill`, `till`, `account_ref`), `is_transfer`, `transfer_pair_id`, `parse_confidence`, `raw_hash`, `note` |
| `duplicate` | same keys as `parsed` (the line parsed but dedupe dropped it); `is_transfer` false, `transfer_pair_id` null |

`id` = deterministic UUID of `sha256("<pack_id>|<family_id>|<raw_hash>")` (first 32 hex, version nibble `4`, variant
nibble from `89ab`); `transfer_pair_id` = the same derivation of `"transfer|<out id>|<in id>"`. `raw_hash` is the
SHA-256 of the untouched body. See `packages/pack-engine/README.md` for every other rule.
